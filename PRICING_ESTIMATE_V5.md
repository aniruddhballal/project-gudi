# Vasavi Penugonda Revamp — Pricing Estimate V5

## Purpose

V4 used an equal ₹15L / ₹15L split only because the available scope was primarily from the frontend perspective. This version reflects the fact that backend work may carry greater architectural, security, payment, infrastructure, and operational responsibility.

Lalith's 11-week demo remains a phase/payment reference only. It is not the Vasavi timeline.

## Timeline

- Discovery and planning: 2–4 weeks
- V1 public website: 12–18 weeks
- V2 API integration: 8–14 weeks
- Admin/CRM system: 12–18 weeks
- QA, deployment, training, handover: 4–6 weeks
- Part-time capacity: 10–18 hours/week per engineer
- Overall: **38–60 calendar weeks**, approximately **9–14 months**
- No 11-week deadline

Frontend and backend work can run in parallel, but API readiness and temple review cycles may extend the calendar duration.

## Why backend may be higher

- Database and API architecture
- Auth and role enforcement
- Payment security and webhook handling
- Refunds, receipts, reconciliation, and auditability
- Media storage and file security
- Booking rules and third-party integrations
- Hosting, backups, monitoring, deployment, and production support

Frontend remains substantial because it includes two public-site builds, full UI/UX, content migration, multilingual UX, admin/CRM screens, API integration, QA, SEO, and accessibility.

## Final split before Lalith's scope review

- **Minimum defensible:** Frontend ₹13.5L / Backend ₹15L
- **Recommended:** Frontend ₹14L / Backend ₹16L
- **Upper-end:** Frontend ₹15L / Backend ₹18L

## Details required from Lalith before finalising

- Backend stack and hosting approach
- Number of database entities and API modules

- Booking scope: third-party integration or custom system
- Media storage, upload, processing, and CDN responsibilities

- Estimated backend hours and availability
