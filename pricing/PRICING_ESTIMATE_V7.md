# Vasavi Penugonda Revamp — Pricing Estimate V7

## Position of this version

This version recalibrates V6 for the actual engagement:

- Two independent engineers, not a full agency team
- Aniruddh owns the frontend only
- Lalith owns the backend, database, server, hosting, and server-side payment work
- Part-time delivery, approximately 10–18 hours per week per engineer
- Aniruddh has early-career experience but is independently handling a broad frontend programme
- Booking remains separately priced until its provider and requirements are confirmed

The pricing below is a direct-client project estimate, not a salary calculation and not an agency-premium quote.

## Core project scope

### Frontend — Aniruddh

- Existing-site discovery, page/content/media inventory, and route mapping
- New responsive visual system and UX direction
- V1 hardcoded public website on the alternate domain
- Migration of visible pages, articles, news, events, trustees, galleries, images, videos, documents, donations, and contact information
- V2 API-driven public website
- Loading, empty, error, retry, and permission-aware states
- Multilingual frontend integration
- Donation/payment UI using backend-provided contracts
- Booking UI/integration if a third-party provider is confirmed
- Admin/CRM frontend with login, roles, dashboards, logs, CRUD, media, revisions, publishing, recovery, search, and filtering
- Accessibility, SEO, redirects, responsive QA, browser testing, and handover

### Backend — Lalith

- API and database architecture
- Public content APIs and admin/CRM APIs
- Authentication, roles, permissions, and sessions
- Media/document storage and upload APIs
- Payment orders, Razorpay integration, webhooks, payment states, logs, receipts, and approved reporting
- Multilingual content model
- Search, filtering, pagination, revisions, publishing, recovery, and audit history
- Booking integration or custom booking backend, if approved
- Server, hosting, deployment, monitoring, backups, security, and backend documentation

## Monthly alternative

Use a monthly model if the client cannot freeze scope or if API readiness is uncertain.

| Workstream | Monthly range | Expected capacity |
|---|---:|---:|
| Frontend — Aniruddh | ₹45,000–₹70,000/month | 10–18 hours/week |
| Backend — Lalith | ₹65,000–₹95,000/month | 10–18 hours/week |
| **Combined** | **₹1,10,000–₹1,65,000/month** | Part-time, per engineer |

Recommended monthly position:

- Frontend: **₹60,000/month**
- Backend: **₹80,000/month**
- Combined: **₹1,40,000/month**
- Minimum commitment: 3 months
- Unused hours do not roll over
- New features and booking are estimated separately

The monthly model should be preferred if the client expects continuing discovery, API changes, repeated review cycles, or frequent content decisions.

The previous ₹30,00,000 total was an agency-scale estimate and is not the recommended direct-engineer quote for this engagement. A ₹50,000 total frontend quote would cover only discovery or a small website slice, not V1, V2, and the admin frontend together.

## Exclusions

- Backend/API/database implementation from the frontend quote
- Server, hosting, infrastructure, deployment ownership, and monitoring from the frontend quote
- Payment-provider fees and bank charges
- Translation and language-content creation
- New photography, video production, or copywriting
- Mobile applications
- Custom booking logic unless separately approved
- Unlimited revisions or new feature requests
- Long-term maintenance beyond the agreed defect-support period
